STUDENT EXPENSE TRACKER
IDE CLASS ACTIVITY

PROJECT DESCRIPTION

Student Expense Tracker is a simple web-based application designed to help students manage and monitor their daily expenses.

The application allows users to set a monthly budget, add expenses, select expense categories, view total spending, and check the remaining balance.

TECHNOLOGIES USED

1. HTML
   Used to create the structure and content of the webpage.

2. CSS
   Used for designing the webpage, including the dark theme, layout, cards, buttons, forms, and responsive design.

3. JavaScript
   Used to add functionality such as adding expenses, calculating the total amount spent, filtering expenses, deleting expenses, and updating the remaining balance.

4. Local Storage
   Used to save the budget and expense data in the browser so that the information remains available after refreshing the webpage.

MAIN FEATURES

• Set monthly budget
• Add expenses
• Select expense category
• Select expense date
• Calculate total expenses automatically
• Calculate remaining budget
• View expense history
• Filter expenses by category
• Delete expenses
• Store data using browser local storage
• Mobile-friendly design
• Dark mode interface

HOW TO RUN THE PROJECT

1. Open the project folder.
2. Open the file named "index.html".
3. The Student Expense Tracker will open in a web browser.
4. Enter a monthly budget.
5. Add expenses using the expense form.
6. The dashboard will automatically display the total spent and remaining balance.

CONCLUSION

The Student Expense Tracker provides a simple and user-friendly way for students to keep track of their spending and manage their monthly budget using basic web technologies.
